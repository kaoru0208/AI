# fxbot – AI 自動売買システム

## 概要
fxbot は OANDA REST API で完全自動 FX トレードを行う Python ボットです。  
LSTM / 強化学習モデル、Optuna による最適化、Docker デプロイに対応します。

## セットアップ
\`\`\`bash
git clone <your-repo-url>
cd fxbot
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
\`\`\`
